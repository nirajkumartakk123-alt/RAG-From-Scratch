A Transformer is a deep learning architecture designed to process sequential data and understand relationships between different elements in a sequence. Transformers were introduced in the research paper *Attention Is All You Need*, published by Google researchers in 2017. Before Transformers, recurrent neural networks (RNNs) and long short-term memory networks (LSTMs) were widely used for natural language processing tasks. These architectures process information sequentially, which can make training slower and make it difficult to preserve information across long sequences. Transformers address many of these limitations through an attention mechanism that allows the model to identify relationships between different tokens in an input sequence. Unlike traditional recurrent architectures, Transformers can process multiple input tokens in parallel during training, making them suitable for modern GPUs and other accelerators. Today, Transformers power large language models, machine translation systems, text summarization applications, image understanding systems, and multimodal AI applications. Popular Transformer-based models include BERT, GPT, and T5. The original Transformer architecture consists of an encoder and a decoder. The encoder processes input tokens and creates contextual representations, while the decoder generates output tokens using previously generated tokens and, in the original architecture, information from the encoder. Encoder-only models, such as BERT, are commonly used for language understanding and representation tasks, whereas decoder-only models, such as GPT, are widely used for text generation. Encoder-decoder models, such as T5, are useful for sequence-to-sequence tasks. To understand Transformers, it is important to understand tokenization. A token is a unit of text that may represent a complete word, part of a word, punctuation, or another text fragment. A tokenizer converts text into tokens and maps those tokens to numerical token IDs. These IDs are then converted into dense vectors through an embedding layer. Embeddings provide numerical representations that neural networks can process. However, embeddings alone do not necessarily communicate the order of tokens. Therefore, Transformers incorporate positional information through techniques such as positional encodings, learned positional embeddings, or rotary positional embeddings. Positional information helps the model distinguish between different token positions. The central component of a Transformer is the attention mechanism, particularly self-attention. Self-attention allows each token to incorporate information from other tokens in the sequence. For example, in the sentence "The animal was tired because it had been running," attention can help the model relate the word "it" to "animal." The model learns these relationships from training data rather than following manually written grammatical rules. Self-attention relies on three important components called queries, keys, and values. Queries represent the information a token is looking for, keys represent features used to determine the relevance of other tokens, and values contain the information that is combined to produce the attention output. Query, key, and value vectors are created using learned linear transformations of token representations. The model calculates attention scores by comparing queries with keys, typically using dot products. These scores are scaled by the square root of the key dimension to prevent excessively large values. A softmax function converts the scores into normalized attention weights, which determine how much each value contributes to the final representation. The resulting output is a weighted combination of value vectors. Transformers use multi-head attention to learn different relationships simultaneously. Each attention head has its own learned query, key, and value projections, allowing different heads to focus on different linguistic, positional, or semantic patterns. The outputs of these heads are combined through concatenation and a learned linear projection. After attention, the Transformer applies a feed-forward neural network to each token representation. This network generally consists of linear transformations and nonlinear activation functions, such as GELU. Feed-forward layers transform the features extracted by attention and allow the model to learn more complex representations. Transformer blocks also use residual connections and layer normalization. Residual connections help information and gradients flow through deep networks, while layer normalization helps stabilize training. Multiple Transformer blocks are stacked together to build increasingly sophisticated representations. Model depth refers to the number of layers, while model width generally refers to the dimensionality of its hidden representations. Increasing model size can improve capabilities, but it also increases computational and memory requirements. Training a Transformer involves feeding data into the model, calculating a loss, computing gradients through backpropagation, and updating parameters using an optimizer such as AdamW. GPT-style language models are commonly trained through next-token prediction, where the model learns to predict the next token based on the preceding tokens. Cross-entropy loss is commonly used to measure the difference between predicted token probabilities and the actual next tokens. Causal attention masks prevent decoder-only models from accessing future tokens during training. BERT, on the other hand, was originally trained using masked language modeling, in which selected input tokens are hidden and predicted. Pretraining teaches models general patterns from large datasets, while fine-tuning adapts pretrained models to particular tasks or behaviors. Supervised fine-tuning uses examples containing inputs and desired outputs, and preference-based alignment methods can further influence model behavior. During inference, a trained language model generates text by predicting tokens, often one at a time. Generation strategies include greedy decoding, temperature-based sampling, top-k sampling, and top-p sampling. The context window determines how much input and generated text the model can handle in a sequence. Standard full self-attention has computational complexity that grows quadratically with sequence length in its attention-score calculations. Efficient attention implementations can reduce memory requirements and improve performance. During autoregressive generation, a key-value cache stores previously calculated attention keys and values, avoiding unnecessary recomputation. Quantization can reduce memory consumption by representing parameters or computations using lower-precision numerical formats, while knowledge distillation trains smaller models to reproduce useful behavior from larger models. Transformers can also process images by representing image patches as sequences, as demonstrated by Vision Transformers. Multimodal Transformers can combine text, images, audio, and other forms of information. Understanding tokenization, embeddings, positional information, attention, feed-forward networks, training, and inference provides a strong foundation for working with modern AI systems.
